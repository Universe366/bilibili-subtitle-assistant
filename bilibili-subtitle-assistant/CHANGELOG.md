## 1.64.0（2026-10-20）

### 新增
- **检查更新**：设置 → 诊断与关于 → 版本更新，显示当前版本、最新版本、上次检查时间。
- **自动检查**：每天一次（`chrome.alarms`），结果缓存 24 小时；可在设置中关闭。
- **手动检查**：忽略缓存，立即向 GitHub Releases 查询。
- **新版本说明**：直接展示 Release 正文，可折叠。
- **打开下载页**：一键打开 Release 页面；私有仓库至少还能在浏览器登录状态下访问。

- `content_scripts.matches` 从 `*://*/*` 收窄为 `*://*.bilibili.com/*`，不再申请全站内容脚本权限。
- 新增 `alarms` 权限。
- 构建模块 17 → 19。

### 文档
- 新增根目录 `PRIVACY.md`（Edge 商店隐私政策底稿）。

## 1.63.12（2026-10-20）

### 调整
- 总结不再列来源、不标 `[来源 N]`、不出现「待核实」，也不再注入字幕更正清单，避免正文臃肿。
- 核对证据先经一次 AI 提炼成 **0~3 条简短「外部补充」**，只在确实能补充/纠正视频内容时自然融入；没有就忽略。
- 中文只出现一次的短词不再作为检索项；多词查询至少命中两个词，减少「搜出来跟内容无关」的情况。
- 移除「总结末尾附来源」设置；保留 12 条 / 1~16 的核对范围与前后段抽样。
- 「生成总结前联网核对」仍然不受「对话时自动联网」开关影响。

## 1.63.11（2026-10-20）

### 改进
- 联网核对范围扩大：默认抽 **12 条**待核实项（可调 1~16），按字幕前 / 中 / 后段抽样，避免反复出现的开头术语占满名额。
- **同一批核对证据会交给总结阶段**：总结正文可引用 `[来源 N]`；证据与字幕冲突或不足时提示「待核实」。
- 总结末尾默认附**联网核对来源**列表（编号与正文对应，可在设置关闭）。
- 「生成总结前联网核对」不再受「对话时自动联网」开关影响。
- 设置页补上「总结末尾附来源」开关，并把「每次核实几条」上限同步到 16。

### 安全
- 交给模型的核对证据统一包进 `<untrusted-web-content>` 边界，并明确要求不执行其中的指令。

## 1.63.10（2026-10-19）

### 新增
- **DeepSeek 官方搜索**：接入 `POST /v1/tools/search` 与 `/v1/tools/fetch`，复用 AI 平台里的 DeepSeek Key，无需再填一次。结果保留 `summary`、`rerank_score`、`authority`、发布日期与站点，按相关度排序后去重。
- 检索词清理（去掉「帮我查一下 / 请问」等口语前缀），原问题作为 `ori_question` 透传；时间过滤映射为 `after:` 查询语法。
- 来源面板优先展示 `summary`，带站点与发布日期，悬停可看更长摘要。
- 自动检索判定收紧：「为什么 / 多少 / 对比 / 区别」这类泛问句不再触发联网。

### 修复
- 检索缓存键补上 `oriQuestion`，不同原问题不再共用缓存。
- 外部 `chrome.storage` 变更会让 service worker 的设置缓存失效。
- 检索结果 URL 只保留 `http(s)`，避免 `javascript:` / `data:` 进入来源链接。
- 身份校验签名透传、页面调用超时映射（`fetchAudioRange` 不再被 15s 掐断）。
- 字幕菜单触发按当前视频过滤，尝试次数按视频重置。
- 「清除」API Key 现在会真正清空。
- 长视频分段总结可以终止；生成总结的校对阶段也可以终止。
- 「刷新页面」改为真正 reload（新增 `tab.reload`）。
- 字幕行编辑按 Esc 取消不再被 blur 误保存。
- 向导不可被 × / Esc 绕过，第 1 步能正确展开 AI 分组。

### 其它
- 音频下载入口归一：整条音轨与分块下载都走 `audio.range`（页面优先、后台兜底）。
- 嗅探缓存加上限（字幕 32 条 / 音轨 16 条），长会话不再慢性增长。
- 批量队列按钮按状态禁用；批量输入在重绘后保留。
- 「清空字幕」加二次确认，并提示可从操作留痕回退。
- 清理未实现的音频缓存配置、3 个无引用配置键与 17 个死函数。

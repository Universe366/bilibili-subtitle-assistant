## 2.11.0（2026-10-21）

### 修复
- **联网检索偏差**：中文查询不再被当成一个整词判定。改为「英文/数字实体 + 中文二字组（按位置加权）」匹配，`DeepSeek-V4` / `DeepSeek V4` / `deepseek_v4` 互通；只共享「发布 / 模型」这类泛词的网页会被判为不相关。
- 相关性判断纳入 `summary` 与正文前 2000 字，不再只看标题 + 短摘要。
- 只查单个实体（如「DeepSeek」「达摩院」）时，用字幕里该词所在的原句做上下文过滤：只提到名字、没谈字幕里那件事的网页不再算证据。
- 校对证据优先取 `summary`（给模型看的 600~800 字版本），先按与检索词的贴合度、再按平台 rerank 分数排序；空摘要的结果不再占名额。
- **证据语义判定**：一次 AI 调用把每条证据标成「支持 / 反驳 / 无关」，无关证据直接移除；这次调用同时产出 0~3 条外部补充，替代原来独立的补充调用，不增加请求数。
- **多来源一致 / 冲突**：按独立域名统计，只有两个以上不同站点都支持才标「多来源一致」；同一站点的两篇文章不算两个来源。只有多来源一致的补充才写进总结，具体数字 / 时间 / 事实的修正也以它为准；单一来源只作参考。
- 核对改为 3 路并发（优化流程 2 路），保持结果顺序；12 条核对的等待时间明显下降，仍可随时终止。
- 「本次联网核对」为每条查询标出来源强度（多来源一致 / 单一来源 / 来源冲突），每条证据标出「支持 / 反驳 / 未判定」，并显示判定产生的补充。
- AI 生成的检索词必须能在视频标题或字幕里找到实体依据，并尽量还原「实体 + 时间 / 数字 / 版本」的具体说法；行业空话与凭空编出的实体会被丢弃并回退到规则抽取。
- **检索词改为「字幕原句」**：自动取命中行与前后相邻行拼成语境窗口，不再把 `6710 亿`、`2026` 这种孤立数字或短语直接发出去；字幕一行只有半句时也能带上主语。
- AI 生成检索词前，先从全文抽取「实体 + 具体说法」的候选句（带前后语境）一起交给模型，不再只看 3600 字的开头/中间/结尾节选。
- 长中文查询的相关性判定改为「实体 + 至少一个限定词」，不再要求命中一半以上的二字组 —— 否则按整句检索时几乎必然全灭。
- 优化提示词与总结补充改用字幕原句作为核对项上下文，模型不再只看到一个孤立术语。
- **「本次联网核对」只展示真正拿到相关证据的查询**，不再列出十几条「0 条证据」的检索词；每条附上对应的字幕原句与证据摘要，方便判断有没有用。
- 修复 AI 优化流程里漏导入 `extractVerifyItems` / `verifyItems` 的问题：此前核对会抛错并被静默吞掉，每次都退回整篇搜索。
- 对话不再默认复用上一轮检索结果；只有用户明确问「这些来源 / 刚才搜到的」时才复用。结果与当前问题相关性过低时会明确告诉模型「已省略」，而不是把无关网页塞进上下文。
- 逐条核对恢复为每条只取 3 条来源（此前被设置里的全局 6 条覆盖），减少无关结果与额度消耗。

### 说明
- 检索词生成与初筛仍是启发式；语义判定依赖模型，模型也可能判错，因此保留「单一来源 / 冲突」标签，并禁止只凭单一来源修改具体数字 / 时间 / 事实。

# 更新记录（桌面端）

## 0.32.0（2026-10-23）

### 浏览器
- 新增历史记录（可搜索、可清空）、书签（地址栏星标 / `Ctrl+D`）、下载记录（进度、打开、定位、移除）。
- 新增「历史 / 书签 / 下载 / 标签」面板；`Ctrl+Shift+A` 标签搜索。
- 启动时恢复上次标签页（可在设置里关闭）；`Ctrl+Shift+T` 重开最近关闭的标签。

### AI
- 对话不再限制 B 站视频页：任意网页可读取正文与选中内容提问，页面内容按不可信资料处理。
- `Ctrl+Shift+S` 带着选中内容直接提问；选中网页文字时出现「解释 / 翻译 / 总结」浮动工具条（设置里可关闭）。
- 对话面板显示页面字数与选中字数，可关闭「带入页面」。
- 对话面板新增「总结本页 / 存入库」：把网页总结直接存进本地库（没有字幕也能入库）。
- 支持导入本地音视频：选择文件 → 语音识别 → 入库，可在任务中心看进度。
- 支持播客 / RSS：粘贴订阅地址，选择单集后下载音频、语音识别并入库。
- 新增 YouTube 支持：读取 `ytInitialPlayerResponse` 的官方/自动字幕，视频页可按字幕总结、入库；「导入链接」支持 YouTube 单条视频。
- 新增本地只读工具：搜本地库、读条目、列最近入库（设置 → AI 可关闭）。
- 本地模型免 Key：Ollama / LM Studio 预设，localhost 端点不再要求 API Key。
- 空库新增「粘贴链接 → 导入并总结」入口。

### 品牌
- 对外显示名改为「拾字 / Shizi」，副标题「视频与网页的 AI 笔记工作台」。
- 技术标识（appId、userData、安装包 productName）暂不改变，避免打断自动更新；见 `docs/REBRAND.md`。

### 数据
- schema 升到 v3：新增历史、书签、下载表；老库启动自动迁移。

### 稳定性与安全
- 新增单实例锁：重复启动只聚焦已有窗口，不会再让第二个进程把第一个进程的任务标记为中断。
- API Key 改用系统 DPAPI（`safeStorage`）加密落盘，老版本明文启动时自动迁移。
- 导出设置、数据备份、诊断包不再包含 API Key 与桥 Token；恢复备份保留本机 Key。
- 新增站点权限闸门：摄像头 / 麦克风 / 通知 / 剪贴板 / 位置首次请求时弹窗，可按站点记住，默认拒绝。
- 生产构建给应用 UI 注入 CSP（只作用于应用界面，不影响内嵌网页）。
- 删除条目改为进入回收站（保留 30 天 / 最多 200 条），可恢复字幕、总结、笔记、标签与合集。
- 新增 schema 版本号与顺序迁移框架，老库启动自动升级。
- 数据备份增加 SHA-256 校验，损坏或被修改的备份会拒绝恢复。
- 设置 → 数据与备份新增「压缩数据库」（`VACUUM` + `PRAGMA optimize`）。

### 可观测性与工程
- 新增统一日志：`logs/main-YYYY-MM-DD.log`，保留 7 天，落盘前脱敏。
- 新增「导出诊断包」：版本、数据规模、脱敏设置、站点权限、日志。
- 新增 ESLint / Prettier、Vitest（56 个用例）与 PR CI（typecheck / lint / test / build）。

## 0.31.0（2026-10-23）

### 界面主线（重要）
- 侧栏收敛为 **字幕 / 总结 / 对话 / 库 / 设置** 五项，移除独立的「批量」「记录」入口。
- 库成为唯一管理入口：顶部只保留「＋合集 / 导入链接 / 筛选 / 选择」，排序、标签、合集管理收进「筛选」。
- 批量能力并入库：选择视频后底部出现「批量总结 / 加标签 / 加合集 / 删除」，并发 1–4 可选。
- 任务与导出合并到侧栏底部「任务」抽屉：任务进度、暂停/继续、取消、失败重试，以及导出记录。
- 空库提供「打开 B 站 / 导入链接」两个明确的下一步。

### 合集 / 多 P 导入
- 新增 B 站合集解析：识别 UP 主合集（`ugc_season`）与多 P 视频，一次生成全部视频链接。
- 「导入链接」支持先「识别合集 / 多 P」，确认合集名与数量后一键导入全部。
- 字幕面板新增「合集」按钮，可直接导入当前视频所在合集（只入库，不自动总结）。

### 库与整理
- 条目详情：离线字幕、总结、笔记三个页签；标签/合集 chips、导出、删除。
- 标签：增删、重命名（合并同名）、删除；合集：新建、重命名、删除、按合集筛选。
- 多选批量：批量总结、加标签/合集、批量删除；空标签/合集自动清理。
- 库/全局搜索覆盖标题、UP、标签、合集、笔记、字幕正文、总结与合集对比。

### 总结与笔记
- 总结保留最近 20 个版本，可预览、与当前版本 diff、恢复。
- 笔记：停止输入 1.2 秒自动保存，`Ctrl+S` 手动保存；保留最近 20 个版本，可载入；支持预览、导出 Markdown，正文参与搜索。

### 合集对比
- 合集管理里点「对比」，用各视频总结/字幕生成跨视频对比：速览表、共识、分歧、推荐观看顺序。
- 对比结果保留最近 20 个版本（预览/恢复）、可导出 Markdown、可被全局搜索命中。

### 批量与任务
- 批量总结：并发 1–4、逐项状态、失败重试；停止会保留已完成结果。
- 任务持久化：总结、转录、翻译、校对、批量、链接批量、合集对比都写入任务表，重启不丢。
- 长任务完成/失败/停止且窗口不在前台时发送系统通知。

### 导出与数据
- 导出记录：字幕/总结/笔记/合集对比导出登记在「任务 → 导出」，可打开、定位、移除记录（不删文件）。
- 数据备份与位置迁移保持原行为；新增表均为增量迁移，老库启动自动补齐合集对比版本。

### 修复
- 停止生成时不再把 AbortError 当成失败；已完成结果保留。
- 删除条目后清理空标签/空合集。
- 合集/笔记版本按内容去重，避免自动保存造成版本爆炸。

## 0.30.9（2026-10-22）

### 插件桥（零配置）
- 新增 `GET /v1/hello`：扩展自动发现端口与 Token，设置里不用再手填；网页来源会被拒绝。
- 设置 → 插件桥新增 **「安装浏览器插件」**：定位扩展目录、复制路径并打开 Edge/Chrome 扩展管理页。
- 打包时把扩展源码同步到 `resources/extension`，安装包自带插件。

### AI 平台
- 新增 **Anthropic Claude 原生协议**（`/v1/messages` + `x-api-key`）：总结、对话、翻译、校对、章节、联网核对与 MCP 工具循环都可用 Claude，不再需要第三方 OpenAI 兼容转发。
- AI 请求统一到 `aiClient`：OpenAI 兼容与 Anthropic 两条链路共用超时、错误翻译、流式解析与图片消息转换。
- `max_tokens` 超过模型上限时自动回退到 8192 重试（例如 Claude 3.5 Haiku），不把 400 直接丢给用户。
- 新增 Anthropic 预设（AI 平台 28 家）；老配置通过 `AI_PRESET_VERSION` 自动补入，不影响已填 Key。

### 总结联网核对
- 总结前可让 **AI 从字幕里挑「实体 + 具体说法」生成检索词**（设置里可关），并校验检索词必须在字幕/标题里有落点，避免编造。
- 新增 **额外核实查询**（每行一条），与 AI / 规则抽取的查询合并、去重。
- 核对并发从 2 提到 3，12 条核对的等待时间约降到三分之一。
- 无 Key 兜底支持 **自定义引擎顺序**（Exa / AnySearch / SearXNG），不再只试 Exa。

### 语音识别
- 默认分片 **600s**、并发 **4**、单文件上限 **50MB**、超时 **180s**，与插件对齐；旧默认值（120s / 1 / 20MB / 120s）自动迁移，手动改过的不动。

### 设置
- **探测模型后显示完整列表**：不再只显示前 12 个（ASR 前 8 个），全部模型放进可滚动区域；超过 16 个时提供关键词筛选。
- 模型输入框的候选列表同步探测结果（之前只含内置预设）。

### 面板
- 切换左侧导航不再卸载面板：总结、对话、转录、翻译、优化、批量等任务在切到「设置」等页面后继续运行，返回时状态与结果还在。
- 面板首次打开后保持挂载；隐藏时暂停字幕跟随轮询，避免后台空转。

### AI 总结
- **总结形式与插件对齐**：默认追加飞书格式细则（先给结论 + 速览表格、引用块、代码块、任务列表、emoji 小标题、详细笔记），不再只输出「标题 + 段落」。
- 总结不再注入全部已启用 Skills（插件只在用户显式选技能时注入），避免凭空多出时间轴/术语表章节。
- **联网核对输出改为插件风格**：只给「外部补充 + 待核实证据」，不再要求 [n] 编号/网址，避免总结变成检索报告。
- 核对增强：单条检索失败自动重试一次、每条最多 3 条证据、按站点标注「多源一致 / 来源冲突」。
- 语义判定输出上限提高，判定失败时改为「只整理 0~3 条外部补充」，不再把未判定的网页列表塞进总结。
- 「本次联网核对」改为默认折叠，减少干扰。
- **长视频分段总结**：字幕超过 4 万字符时按 4 万字符一段提取，再合并成完整总结，不再把中间内容截断。
- 新增 **「快速」总结**：跳过「先校对字幕」，直接生成（更快、更省额度）。
- 总结支持 **思考过程折叠显示**（推理模型），流式结束后整体渲染 Markdown。
- 分段阶段在状态栏显示「长视频分段总结 i/n」「正在合并 N 段」。

### 界面
- **修复封面空白**：B 站图片 CDN 按 Referer 防盗链，渲染页的 `localhost` / `file://` Referer 会被 403；渲染页改为 `no-referrer`，视频卡与库封面正常加载（实测 `naturalWidth > 0`）。

### 字幕
- **获取提速**：页面桥改为**先请求 WBI 签名接口**，成功就直接返回，不再依次请求无签名 `player/v2`、播放器实例、`__INITIAL_STATE__`；签名接口明确返回空时也直接结束，不再 6 次轮询。
- **转录/翻译结果刷新后保留**：ASR 与翻译结果按「视频 + 字幕轨」缓存在内存中；刷新/重新获取时自动恢复（翻译同时恢复双语视图），并保留「语音转录」轨可切换。编辑、优化、清空或重新转录会使对应翻译缓存失效。
- **转录结果不再被刷新清掉**：ASR 结果缓存在内存中，刷新/重新获取时如果本视频没有官方轨，会自动恢复转录字幕，并保留「语音转录」轨可切换。
- **关键修复：字幕只信 WBI 签名接口**。无签名的 `/x/player/v2` 在风控降级时会返回**别的视频的字幕**（社区已确认），现在只要 `/x/player/wbi/v2` 请求成功，就完全以它的结果为准，哪怕返回 0 条；无签名结果、播放器实例、`__INITIAL_STATE__` 和网络嗅探只在签名接口失败时兜底。
- **修复「没有字幕却抓到别的视频字幕」**：签名接口返回空时页面桥直接返回 0 轨；配合下面的时长/覆盖率/内容校验，最终显示“没有可用字幕”，不再串片。
- 非全片覆盖（<97%）的字幕再做 **标题/简介关键词校验**：内容完全对不上标题的轨直接拒绝，避免「郎酒视频配京都旅行字幕」。
- 单轨也做时长/覆盖率校验（末句超出片尾 8%+8s 或覆盖低于 70% 直接拒绝），不再只信 B 站接口返回的第一条轨。
- 播放器实际时长与页面信息不一致时先等待（避免 SPA 切页时拿到上一个视频的预取轨）；被拒轨自动重新获取最多 4 次，仍不匹配则明确报错，不显示错误字幕。
- 修复无可用字幕时一直显示「正在下载字幕」：重新获取到同一条轨时也会重新校验，最终失败会停止重试并显示原因。
- **修复字幕串视频**：自动选轨优先「结束时间与视频时长对齐」的轨；末句超出片尾 8%（且 >8s）的轨判为别的视频/整段合集，直接丢弃并置灰，不再按行数最多选中错误轨。
- **翻译视图真正生效**：翻译完成后可在「原文 / 译文 / 双语」之间切换，行内同时显示译文；复制全部与单行复制都遵循当前视图。
- **搜索结果高亮**：查找时命中文字直接高亮，跳转命中行会恢复跟随并滚动到对应位置。
- **清空字幕**按钮：只清当前显示，不删除本地库与缓存；清空后可重新获取。
- **字幕诊断补全**：逐来源错误（来源 / code / message）、被排除的外来轨明细、候选轨判定（可用行数 / 下载失败 / 时长超出 / 覆盖不足）、身份不一致与采集期间切换提示。
- 选中轨下载失败或没有正文时**自动尝试下一条候选轨**（最多 3 条），不再直接停在错误上。
- 没有字幕轨时提供「重新获取字幕」「让播放器重新请求」「改为语音转录」；新增「章节」入口（跳到总结页生成）。
- 拖动进度条大跳转后自动恢复跟随；底部统计补上「朗读约 X」。

### 其他
- 新增 **首次使用向导**：欢迎 → 检查 AI Key → 三步上手；可在「设置 → 诊断与关于」重新显示。
- 字幕正文缓存默认 **30 天**（可设 0 关闭），不再 30 分钟后重新下载。
- 总结工具栏新增 **复制 Markdown**。
- 对话不再强制要求字幕：视频没有可用字幕时仍可提问（简介 / 联网 / 通用问答），提示里会明确「没有字幕依据」。

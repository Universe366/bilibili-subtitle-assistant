# 更新记录（桌面端）

## 0.30.7（2026-10-22）

### 核对、Markdown 与字幕
- 核对检索改为「整句上下文搜索 + 短标签相关性过滤」，只展示有证据的项。
- 总结正文支持 GFM 表格渲染。
- 字幕工具栏新增清空显示（不删除库/缓存）；每行可复制、编辑，并显示起止时间/字数/朗读提示。
- 字幕刷新请求带上当前页面签名；身份不一致直接拒绝，自动选轨增加 70% 时长覆盖要求，避免串到别片/广告轨。
- 总结请求支持切浏览器标签后继续；字幕页新增「总结」按钮，跳到总结并立即生成。
- 输出上限 `maxTokens` 默认/当前为 64000；原字幕上下文上限提高到 200000 字符。

- 字幕行新增复制按钮与起止时间/字数/朗读时长提示。

## 0.30.1（2026-10-22）

### 总结联网核对
- 新增「总结前联网核对」：从字幕分段抽具体数字/年份/版本/英文/重复术语，逐条检索并做相关性过滤。
- 证据以紧凑的待核实项 + 证据块注入总结，不再只按视频标题搜一次、整块塞网页。
- 可配置每次核对条数（1~20），默认 12。
- 证据再做一次 AI 语义判定（支持/反驳/无关），校验引用原文后只保留有效证据，并产出 0~3 条外部补充。
- 多字幕轨默认改为异步选择正文最多的轨，避免选中只有一行广告/贴片的轨。
- 总结下方新增「本次联网核对」面板：待核实项、证据、支持/反驳/未判定、丢弃数、外部补充；证据可点开原文。
- 新增可选「总结时带热门评论」：默认关闭，走 B 站评论接口取 12 条，作为观众观点参考，失败不影响总结。
- 新增「诊断与关于」：版本 / Electron / Chrome / Node / 系统 / 数据目录 / 日志 / 库统计；支持刷新、复制诊断、打开数据目录、反馈入口。
- 核对抽词过滤短大写/低频英文与口语，数字/年份查询带上下文；实测从 `DOO/IPHONE/app/2010年` 收敛到 `2010年/IPHONE/500次/IPAD`。

### 对话与字幕
- 对话新增 Skills 选择器：只注入本轮选中的技能，不再把全部技能塞进上下文。
- 字幕长句改为单行横向滚动，与插件行为一致。

### 更新加固与备份
- 新增「跳过此版本」；自动检查不再提示已跳过的版本，手动检查仍可看到。
- 更新区新增「打开发布页」，检查失败/绿色版可直接手动下载。
- 设置 → 数据与备份新增「备份数据 / 恢复备份」：复制 settings.json 与 library.db；恢复前自动保留 pre-restore 备份并重启。

## 0.30.0（2026-10-22）

### 自 0.2.0 以来的主要变化
- 桌面端完整浏览器：多标签、登录、播放、弹幕、评论、快捷键、标签休眠。
- 字幕：官方多源抓取与诊断、翻译、校对/术语、查找复制统计、导出 6 格式 × 4 模板。
- AI：流式总结、对话（图片/思维链）、章节、优化联网核对、总结前校对。
- 语音转录：音轨下载、M4A/WAV、重叠切片、自适应大小、超时、自动套规则。
- 本地库：SQLite 入库、全文搜索、历史、批量总结、URL 批量抓取。
- 平台：AI 27 家、检索 12 家、ASR 3 家；每平台独立 Key/模型/地址/高级字段。
- 设置：分组折叠、搜索、字号/侧栏宽度、Key 掩码、插件桥、MCP/Skills、数据导入导出。
- 侧栏：拖拽调宽、拖到窄处折叠、标题栏换边、折叠图标随侧别变化。
- 更新：默认启动检查、自动下载、状态/说明/红点；安装版支持自动更新。
- 卸载：自定义卸载页，可选是否删除本地数据。

### 卸载
- 安装包新增自定义卸载页：可选择「只删程序」或「同时删除本地数据」。
- 删除数据时清理 `%APPDATA%\bsub-desktop` 与更新缓存；默认不勾选，避免误删。
- 程序文件、快捷方式和卸载注册项仍由 NSIS 正常清理。

### 更新
- 默认启动后自动检查更新；保留开关与自定义更新源。
- 新增「发现新版本后自动下载」选项。
- 更新状态卡片：当前版本、上次检查时间、错误原因、更新说明 Markdown。
- 侧栏设置项显示更新红点；检查失败可直接重试。

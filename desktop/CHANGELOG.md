# 更新记录（桌面端）

## 0.9.0（2026-10-22）

### 新增
- 批量总结：勾选库内视频，串行生成 AI 总结，支持进度、停止、失败原因。
- 历史：查看 / 展开总结、打开原视频、删除单条、清空全部。
- 字幕缓存：同一字幕轨 30 分钟内复用，最多缓存 100 条。

## 0.8.0（2026-10-22）

### 新增
- 导出扩展：新增 WebVTT、ASS（字号可配），共 6 种格式。
- Markdown 4 种模板：纯内容 / 带时间戳 / 学习笔记 / 会议纪要。
- 翻译结果可随 VTT / ASS / SRT / Markdown / TXT / JSON 导出；文件名支持 `{lang}`。

## 0.7.0（2026-10-22）

### 新增
- AI 优化字幕：逐条校对错别字 / 同音字 / 标点 / 专有名词，返回改动列表，
  支持逐条勾选、全部应用、取消；ASR 结果优化后同步更新转写缓存。
- 设置页新增「AI 优化提示词」。

## 0.6.0（2026-10-22）

### 新增
- 字幕翻译：按行批量翻译、保留时间轴，支持中文简繁 / 英 / 日 / 韩；
  原文 / 译文 / 双语视图；翻译结果可随 Markdown / TXT / SRT / JSON 导出。
- 设置页新增「翻译提示词」；导出文件名支持 `{lang}` 变量。

## 0.5.0（2026-10-22）

### 新增
- 语音转录（ASR）：页面音轨候选 + Range 下载、ffmpeg 解码切片（M4A/WAV）、
  硅基流动 / Groq / OpenAI / 自定义平台、multipart / base64 / chat-audio 自动回退、
  并发、取消、进度；转写结果可直接入库、导出、总结与对话。

## 0.4.0（2026-10-22）

### 新增
- AI 对话：基于当前视频字幕流式回答，支持停止、清空、建议问题与 Markdown 渲染。
- 设置页新增「对话提示词」，可自定义回答风格与引用要求。

## 0.3.0（2026-10-22）

### 新增
- 设置页扩展：主题、关闭到托盘、后台标签休眠时长。
- AI 平台管理：新增/删除平台、温度、最大 token、流式输出开关。
- 提示词模板：多模板新增/删除/切换，总结使用当前模板。
- 导出默认值：默认格式、Markdown/TXT 时间戳、文件名模板（`{title}` / `{bvid}` / `{date}`）。
- 设置导入 / 导出（含 Key 与桥 Token，需妥善保管）。
- 联网检索：Exa / AnySearch 免 Key，Tavily / Brave 需 Key；总结时注入参考资料并标注来源。
- 字幕校对：规则组（正则/大小写）与术语表；读取字幕、外部推送统一应用，术语注入总结提示词，支持预览。
- 数据与诊断：数据目录、数据库路径、日志位置。

### 修复
- 删除内置 AI 平台后保存不再被默认配置加回。

## 0.2.0（2026-10-22）

### 新增
- 自动更新：设置页检查 / 下载 / 重启安装，支持自定义 generic 更新源。
- 后台标签休眠：闲置 5 分钟且未出声时释放渲染进程，切回自动重载。
- 浏览器基本盘：缩放、页内查找、右键菜单、下载保存、常用快捷键。
- 插件桥：外部浏览器把字幕与总结推送到本地库。

### 修复
- 标签重建时 `about:blank` 会覆盖真实 URL，导致页面不加载。
- 「测试连接」改为先保存配置，避免「发送到桌面」读取旧 Token。

## 0.1.0（2026-10-21）

- 首个可用版本：内置浏览器、字幕抓取与跟随播放、本地库与全文搜索、AI 总结、导出、设置、托盘、NSIS 安装包与绿色版。

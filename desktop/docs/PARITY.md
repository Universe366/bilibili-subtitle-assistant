# 插件 → 桌面端功能矩阵

> 目标：插件里**桌面端适用**的功能逐项迁移并跑通。页面注入类功能（内嵌侧边栏、播放器按钮、画面字幕）在桌面端由原生 UI 替代，不迁移。
>
> 验收证据与限制见 [`ACCEPTANCE.md`](ACCEPTANCE.md)。

## 已知限制

- URL 批量需要桌面端登录 B 站才能读字幕；完整入库回归待做。
- ASR / 翻译 / 优化 / 章节目前以 mock 或真实接口的部分链路验证，真实平台回归需用户 Key。
- 检索只有相关性排序与单条证据判定，多来源一致/冲突统计未做。
- MCP 已支持 HTTP/SSE；复杂鉴权头需在设置里手工配置。
- 未签名；0.14.0 尚未发布 Release。

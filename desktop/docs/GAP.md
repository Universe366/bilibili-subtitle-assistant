## 0.30.8 复核结论

桌面端适用的插件功能已全部对齐；下面几项属于「插件里有设置项但未接入行为」或「桌面端原生替代」，不再作为迁移缺口：

| 项目 | 说明 |
|---|---|
| 批量自动导出 / 批次间隔 | 插件 `batch.autoExport` / `pauseBetween` 只存在于默认配置，没有消费方；桌面端批量已支持暂停 / 继续 / 单项移除 |
| 字幕轨「优先官方」 | 插件 `preferOfficial` 只出现在设置页，未参与选轨；桌面端按「正文最多 + 70% 时长覆盖」选轨，已能排除广告/贴片轨 |
| 诊断 verbose | 插件设置项未接入日志行为 |
| 直接搜索引擎 | 桌面端本身就是浏览器，地址栏 / 新标签即原生搜索 |
| 首次使用向导 | 已补齐（0.30.8） |
| 免费引擎顺序 | 已补齐（`keylessOrder`：exa / anysearch / searxng） |

## 不迁移

- 页面内嵌侧边栏、播放器按钮、画面字幕：桌面端本身就是浏览器，由原生 UI 替代。
- MCP stdio 子进程：桌面端可以做，但当前只支持 HTTP/SSE，后续按需补。
